Clone & Make new


Absolutely — here's how to clone an existing GitHub repository, reinitialize it as a fresh local Git repo, and push it to a new GitHub repository.

🧭 Scenario: Clone → Clean → Reconnect to New GitHub Repo
1. Clone the original repo
git clone https://github.com/olduser/old-repo.git


2. Rename or move the folder (optional)
mv old-repo new-repo
cd new-repo


3. Remove the old Git history
rm -rf .git


4. Initialize a fresh Git repository
git init


5. Add all files and commit
git add .
git commit -m "Initial commit from cleaned clone"


6. Create a new GitHub repository
Go to GitHub and create a new repo (e.g., new-repo). Don’t initialize with README or .gitignore.




7. Connect your local repo to the new GitHub repo
git remote add origin https://github.com/youruser/new-repo.git


8. Push to GitHub
git branch -M main
git push -u origin main

🚀 Step-by-Step: Hosting a Vite Site on Hostinger
1. Build Your Vite Project
Run the following command in your project directory:
npm run build


This generates a production-ready version of your site in the dist folder.
2. Prepare for Upload
- Ensure your vite.config.js has the correct base path:
export default {
  base: './',
}


- This ensures relative paths work correctly on shared hosting.
3. Upload to Hostinger
- Log into your Hostinger control panel.
- Open the File Manager or use FTP.
- Navigate to the public_html directory.
